# AI Бухгалтер-калькулятор

Голосовой ИИ-преподаватель для изучения профессии бухгалтера-калькулятора.
Интерфейс поддерживает вопросы на русском и казахском языках.

## Запуск на компьютере

1. Установите Python 3.11 или новее.
2. Скачайте репозиторий.
3. В терминале выполните:

```bash
pip install -r requirements.txt
```

4. Создайте файл `.streamlit/secrets.toml` и добавьте:

```toml
OPENAI_API_KEY = "вставьте-свой-ключ"
```

5. Запустите приложение:

```bash
streamlit run app.py
```

## Важно

- Никогда не добавляйте API-ключ в исходный код или GitHub.
- Для ответов ИИ и голосовых функций нужен OpenAI API key; использование API может быть платным.
- Для публикации приложения настройте `OPENAI_API_KEY` в Secrets сервиса Streamlit Community Cloud.
